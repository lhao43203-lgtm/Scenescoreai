# Scene Score 本地演示包

本压缩包用于产品经理在 Windows 电脑本地查看 Scene Score UI 与交互，不连接数据库或后端 API。

## 启动

1. 先完整解压 ZIP，不要直接在压缩软件中运行。
2. 确认电脑已安装 Node.js 24。
3. 双击 `START_LOCAL_DEMO.cmd`。
4. 浏览器会自动打开 `http://127.0.0.1:4173/`。

查看期间请保留命令窗口。结束演示时，在命令窗口按 `Ctrl+C`，再关闭窗口。

## 演示范围

- 首页视频、橙色遮罩与滚动动画
- 排行榜列表、作品详情和视频预览
- 星级评审与教授评审资料
- 评分方法和投稿页面
- 英文 / 繁体中文切换
- 菜单纸张式页面转场

## 常见问题

- 双击后提示找不到 Node.js：安装 Node.js 24 后重新启动。
- 端口被占用：关闭占用 `4173` 端口的软件后重试。
- 页面没有自动打开：手动访问 `http://127.0.0.1:4173/`。
- 路由刷新：本包自带的静态服务器支持 React Router 路由回退，可直接刷新子页面。
